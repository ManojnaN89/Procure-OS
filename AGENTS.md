# AGENTS.md

This repo's working rules are in `CLAUDE.md`, and they apply to you in full, whatever tool you are. Read it first. Then read `handoff/HANDOFF.md`: the build method, branches and pull requests, and the numbers reserved for each block.

The essentials:
- **Build from the spec:**
  - Build only from the block's spec, `handoff/specs/blockN-spec.md`, and `handoff/specs/blocks9-13-interfaces.md`.
  - Apply its RECOMMENDED defaults.
  - Raise only NEEDS OWNER items and real spec gaps, each with a recommendation.
- **Evals:** never write the block's evals. They are written blind, from the spec, on the owner's machine.
- **Rules for the code:**
  - Money is `Decimal` to the paisa.
  - A model never computes a number a decision uses.
  - Every write goes through an audited service.
  - Sensitive actions are proposals.
  - Segregation of duties holds.
  - Rules are versioned data.
  - Use the business date, never the clock.
- **Numbering:** use only the migration and eval numbers the spec reserves.
- **Git:**
  - Commit as "Nikethan CBC", with no co-author or "generated by" lines.
  - Make one PR per block, into that block's branch (`phase1-blockN`), never `main`.
- **Data and secrets:** never put secrets in the repo or a chat. Use synthetic data only.
